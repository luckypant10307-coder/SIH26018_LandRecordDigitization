      About the map layers
      
      
        
      Record status
      
        
      Each parcel coloured by the stage its record has reached.
      
        
      Land classification
      
        
      Re-coloured by the land class the record itself states.
      
        
      Missing records
      
        
      Parcels on the sheet with no digitised record — the register’s own gaps.
      
        
      Control points
      
        
      The surveyed positions the sheet was aligned to.

      Continuous learning
      
      
    
      
    
      Every human correction is a training signal. The system mines three things from them: character confusions, value aliases, and per-field confidence calibration. Rules only activate once enough evidence has accumulated, so a single typo never reshapes the model.
