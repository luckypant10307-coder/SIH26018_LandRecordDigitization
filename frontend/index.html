    What this installation can handle today. A capability that is unavailable is stated as such, so a clean result never hides a check that was never run.

      Processing pipeline

      1. IntakeDuplicate check against every record already held
      2. Quality assessmentSharpness, contrast, skew and ink coverage; unusable scans are returned for rescan
      3. ReadingDigital text where the file has it, character recognition where it does not, manual queue where neither works
      4. Field identification17 land-record fields located by their labels, in Hindi or English
      5. Script and vocabularyPlace names resolved to the administrative directory’s official spelling
      6. Validation63 checks in three directions: within the record, against other records, against the registry
      7. RoutingAuto-approve, refer for review, or block — decided by severity, not by score alone

      Continuous learning
      
      
    
      
    
      Every human correction is a training signal. The system mines three things from them: character confusions, value aliases, and per-field confidence calibration. Rules only activate once enough evidence has accumulated, so a single typo never reshapes the model.
